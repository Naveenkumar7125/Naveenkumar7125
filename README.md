<summary><h3>1. SRI — AI & ML Enabled Video Analysis and Interpretation System <em>(Click to Expand)</em></h3></summary>

> **Category**: AI/ML · Microservices · Computer Vision  
> **Key Impact**: **Reduced manual CCTV surveillance review time by ~67%** with instance-level summarization.  
> **Tech Stack**: `Python` · `React.js` · `Node.js` · `Express.js` · `MongoDB` · `WebSockets` · `OpenCV` · `YOLOv8` · `Cloudinary` · `Docker`

#### 🎯 Problem & Solution
- **The Problem**: Law enforcement and control room staff face severe fatigue reviewing thousands of hours of passive video during investigations, causing critical response delays.
- **The Solution**: Designed a decoupled microservices architecture with an ingestion gateway, adaptive frame sampler, and Python worker pods running YOLOv8 threat detection (weapons and suspects) in parallel with instant sub-85ms WebSocket alert dispatch.

#### 🏗️ Architecture & Data Flow
```text
 [CCTV IP CAMERA] ─── RTSP (30 FPS) ───> [NODE.JS INGESTION GATEWAY]
                                                   │
                                     (Adaptive Frame Sampler: 3-15 FPS)
                                                   │
                ┌──────────────────────────────────┴──────────────────────────────────┐
                ▼                                                                     ▼
    [PYTHON YOLOv8 INFERENCE]                                              [FACENET BIOMETRIC MATCHER]
   (Weapon & Anomaly Detection)                                           (128-d Vector Cosine Match)
                │                                                                     │
                └──────────────────────────────────┬──────────────────────────────────┘
                                                   │
                                     [MONGODB TEMPORAL ARCHIVE]
                                                   │
                                    [WEBSOCKET ALERT DISPATCH]
                                                   │
                                                   ▼
                                [REACT CONTROL ROOM CONSOLE (<85ms)]
```

#### ⚙️ Engineering Challenges & Trade-offs
- **GPU Saturation**: High 1080p frame ingestion overloaded GPU memory. Implemented an **adaptive keyframe sampling algorithm** that runs at 3 FPS during static scenes, dynamically bursting to 15 FPS on motion triggers (saving 67% GPU overhead).
- **False Positive Elimination**: Applied **temporal frame filtering** across 3 consecutive frames before promoting a confidence score to a high-priority threat alert.
- **Measured Metrics**: **92.4% Detection Accuracy** · **<85ms Alert Dispatch Latency** · **7+ AI Microservices**.

#### 🎯 Architecture & Resilience Design
```text
 [REACT CLIENT] ─── HTTPS / JWT ───> [SPRING CLOUD GATEWAY :8080]
                                              │
                                 [EUREKA REGISTRY :8761]
                                              │
        ┌─────────────────────────────────────┼─────────────────────────────────────┐
        ▼                                     ▼                                     ▼
 [PRODUCT SERVICE :8081]             [ORDER SERVICE :8082]                [INVENTORY SERVICE :8083]
 (Spring Boot / MySQL)               (Saga Orchestrator)                  (OpenFeign Declarative REST)
        │                                     │                                     │
        └────────────────────────────> [RABBITMQ EVENT BUS] <───────────────────────┘
                                              │
                                    [NOTIFICATION SERVICE]
```

#### ⚙️ Architectural Decisions
- **Database-per-Service**: Each microservice manages its own isolated MySQL database schema to prevent coupling.
- **Synchronous vs Asynchronous Boundary**: Used declarative **OpenFeign** clients with Resilience4j circuit breakers for read validations (e.g. inventory check), while mutating orders publish **RabbitMQ event messages** for asynchronous order fulfillment.
- **Measured Metrics**: **<45ms Order Ingestion Latency** · **99.9% Queue Delivery Reliability** · **5 Docker Containers**.
