An interactive seat reservation web app utilizing normalized SQL structures and relational checkups to prevent duplicate reservations and handle concurrent transactions efficiently.

#### 💡 Key Features
- **Interactive Seat Allocator:** Displays an interactive, responsive grid mapping available, locked, and reserved seating.
- **Lock Aggregation:** Manages concurrent booking processes and SQL-level lock allocations.
- **Relational Integrity:** Implements normalized schema models to connect users, theaters, movies, shows, and transactions.

#### 🌐 System Architecture
```
[ Frontend GUI (JS + HTML5/CSS3) ] ──(Transactional Post Request)──> [ PHP Core Controller ]
                                                                             │
                                                                             ▼
[ Seating Layout update ] <────────(Transaction State Update)────── [ MySQL Relational DB ]
```
